ASSUMPTIONS AND UNRESOLVED QUESTIONS

1. ElevenLabs and Qwen adapters exist, but production credentials, quotas, latency, and live provider responses were not verified for this slide.
2. The evidence-file implementation requires the documented durable production mount; the slide does not claim object storage.
3. Google Sheets and Databricks integrations are presented as deployable but setup-required, not as fully provisioned production services.
4. Databricks is manually triggered and does not serve the dashboard directly; forecasts return to Lakebase before application access.
5. Google Sheets is a controlled external view/sync target, not the system of record.
6. ElevenLabs Advisor is omitted because a current production web widget is not verified.
7. The slide intentionally avoids claims for autoscaling, multi-region, containers/orchestration, centralized logs/metrics/tracing/APM, or automated production deployment.
